# decision-log фичи 01 - ядро и загрузчик плагинов

Решения составителя по запросу владельца (2026-11-02), сверенные 2026-11-05 с [SAD](../../03-architecture/design/sad.md) и кодом. Исход «открыто» - допущение, принятое за владельца; «заменено» и «снято» - решение пересмотрено SAD, новое устройство названо в основании.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Своё минимальное ядро, без Cordis и без форка | Cordis как зависимость; форк Cordis | ADR-CH-0001; цена чужой парадигмы и форка у dsh; ядро - `core/` без зависимостей времени выполнения | действует |
| D-02 | Манифест - блок `cyborg` в `package.json` | Отдельный файл; манифест как код | Заменено: манифест - `manifest.json` в каталоге плагина (`electron/src/plugins.ts`), ядро разбирает объект до запуска кода (`core/src/manifest.ts`) | заменено |
| D-03 | Плагины - папки в одном пакете, не отдельные npm-пакеты | pnpm workspaces на плагин | `playground/plugins/<id>`, `core/examples/plugins/<id>`; границу держит проверка импортов (`core/test/plugin-imports.test.ts`) | действует |
| D-04 | Статус `Waiting` с названием недостающего сервиса виден пользователю | Молчаливое ожидание (как dsh) | Заменено: граф контрактов разрешается до запуска кода, нет поставщика - отказ с причиной «нет поставщика X» в журнале ([SAD, 3.2](../../03-architecture/design/sad.md#32-загрузка-плагинов)); `waiting` теперь значит «ждёт ленивой активации» | заменено |
| D-05 | Тайм-бокс активации 30 с, бэкофф до 60 с | Без тайм-бокса | Заменено сторожем: пинг раз в 1 с, порог 5 с, выключение после трёх зависаний подряд ([SAD, 3.5](../../03-architecture/design/sad.md#35-изоляция-сбоев-хосты-и-сторож)) | заменено |
| D-06 | Ленивая активация по умолчанию для окон, `startup` для оболочки | Всё при старте | Заменено: плагин активируется при старте, ленивую активацию объявляет манифест (`"activation": "lazy"`, [SAD, 3.2](../../03-architecture/design/sad.md#32-загрузка-плагинов)) | заменено |
| D-07 | Нужны ли **сторонние** плагины вообще | Только внутренняя модульность | [SAD, 3.5](../../03-architecture/design/sad.md#35-изоляция-сбоев-хосты-и-сторож) и [SAD, раздел 6](../../03-architecture/design/sad.md#6-этапы): да; в этапе 1 - из каталога пользователя, всегда один в своём хосте; установка и согласие - этап 2 по поводу | закрыто SAD |
| D-08 | Структура репозитория: `src/core`, `src/plugin-api`, `src/plugins/<id>` | Отдельные пакеты | Заменено кодом: `core/` (ядро), `contracts/` (`@cyborg/contracts`), `playground/plugins/<id>` | заменено |
| D-09 | Первый пилотный плагин - `path-drop` | `search`; `command-buttons` | Снято: перенос функций Cyborg - план репозитория Cyborg, не этого | снято |
| D-10 | Реестр API на аудит - файл `plugin-api/AUDIT.md`, проверка скриптом | Без реестра | Снято: API плагинов - пакет `@cyborg/contracts` с семантическими версиями ([SAD, 3.3](../../03-architecture/design/sad.md#33-версии-и-миграции)); `experimental_` и реестр аудита не заводились | снято |

## Снятые единицы

| ID | Причина |
|---|---|
| FR-CH-1011 Атомарная перезагрузка | Загрузки новой версии плагина поверх работающей нет: установки в этапе 1 нет ([SAD, 6.1](../../03-architecture/design/sad.md#61-этап-1-ядро-без-изоляции-доступа)); выгрузка и загрузка без перезапуска окна - в FR-CH-1007 |
