# Критерии приёмки без теста: исключения

Правило (задача #230, решения владельца 2026-11-11): у каждого критерия истории `ST-NNNN/k` (`docs/03-requirements/*/stories/`), кроме отмеченного `[целевое поведение]`, есть либо тест, чьё имя несёт ключ критерия (`ST-1002/4: ...`), либо строка в таблице ниже. Охват тестов - ядро и адаптер Electron без окна; окно, инструменты автора, документы, замеры и этап 2 - исключения с причиной. Критерий, который ядро не выполняет, код не чинится: исключение «ручная, дефект #N» и задача на дефект.

Проверка - `npm run check:acceptance` (шаг CI «ссылки в docs»); сводка исходов - [acceptance-coverage.md](acceptance-coverage.md), собирается этой же командой с `--write`. Запуск размеченных тестов - `npm run test:acceptance`.

Категории: `окно`, `инструменты автора`, `документы`, `замеры`, `этап 2`, `ручная` (проверка руками на живом окружении, команда названа в причине), `ручная, дефект #N` (ядро критерий не выполняет; `#?` - задача ещё не заведена).

| ST-1006/5 | замеры | Бюджеты NFR-CH-1001 проверяют замеры `npm run spike:gateway`, спайки хостов и `check:budgets` (медиана трёх прогонов на железе CI), а не тест с утверждением |
| ST-1007/7 | окно | Вопрос человеку о живых pty при закрытии окна задаёт главный процесс приложения и окно; в охват (ядро и адаптер без окна) не входит, смотрит `npm run smoke` |
| ST-1009/2 | ручная | Правило выбора места для задачи (плагин или ядро) применяет разработчик и проверяет ревью PR; поведением кода не выражается. Гейт `core/test/plugin-imports.test.ts` держит только чистоту импортов |
| ST-2003/4 | окно | Плашка «Перезапуск» и блокировка ввода рисуются окном поверх фрейма вида; ядро отдаёт только состояние `restarting` (оно проверено в ST-1001/8). Смотрит `npm run smoke` |

| ST-7001/4 | ручная, дефект #? | Нижняя граница `engines.cyborg` у автора не выполнена: шаблон держит `"cyborg": "^1"`, сборка `cyborg-plugin build` версию API в манифест не подставляет, `checkPlugin` о диапазоне без нижней границы не предупреждает (SRS 07, FR-CH-7010: «Ещё нет: шаблона, сборки, `checkPlugin`»); критерий при этом не помечен `[целевое поведение]` |

| ST-7004/3 | документы | Граница доступности на странице руководства о видах (`docs/guide/`) - текст документа; смысл проверяет ревью, сборка сайта `site` (`npm run verify`) держит страницу в сборке |
