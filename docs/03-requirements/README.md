# Нормы

BRD фич, FR и NFR Cyborg Harness. BR фичи (`brd-feat.md`, `BR-CH-<N>NNN`) выведены из [BRD продукта](../01-product/brd.md); FR и NFR выведены из них и из [сценариев](../02-use-cases/README.md): FR - из шагов и расширений сценариев, NFR - из мер BR и ограничений, и каждая норма в `traced from` называет BR своей фичи (норма без потребности - «находка D-NN» журнала решений). Цепочку проверяет `npm run check:docs-trace`. Фича - папка `<NN>-<слаг>/` с файлами `brd-feat.md`, `srs.md` и папкой `stories/` с историями (`ST-NNNN`, критерии приёмки в виде Дано - Когда - Тогда с метками норм и веток сценариев); у фичи, прошедшей решения, рядом лежит `decision-log.md`. Какой критерий закрывает какую норму и какую ветку сценария - [таблица покрытия](coverage.md); её собирает и проверяет `npm run check:docs-trace`. Критерий на то, чего ещё нет (нормы с «Ещё нет»), несёт метку `[целевое поведение]`, и таблица показывает такие критерии отдельной колонкой, чтобы покрытие не читалось как «проверено» (принято по поручению владельца 2026-11-10).

Номер единицы сквозной и при переносе в другую фичу не меняется: принадлежность задают папка и поле `feature`. Новая единица берёт номер из блока своей фичи - фича 03 нумерует с 3001, фича 07 с 7001. Поэтому в фиче 04 лежат FR-CH-1010 и NFR-CH-1004: они выведены раньше, когда фич было две.
