# ST-3007 Установка стороннего плагина с согласием человека (этап 2)

Как человек, устанавливающий плагин от автора вне команды, я хочу видеть права словами и подтверждать установку, чтобы плагин не появился без моего согласия.

Нормы: FR-CH-3021, FR-CH-3022, FR-CH-3023, FR-CH-3024. Сценарии: UC-SECURITY-TRUST-3001. SRS - [srs.md](../srs.md).

> Этап 2: исполнения ещё нет (нормы FR-CH-3022, FR-CH-3023, FR-CH-3024 помечены «Ещё нет»); критерии описывают целевое поведение и станут проверяемыми вместе с изоляцией доступа.

## Критерии приёмки

1. [FR-CH-3024] [UC-SECURITY-TRUST-3001#1] [UC-SECURITY-TRUST-3001#2]
   - Дано источник плагина, выбранный человеком в «Плагины Cyborg», с неверным хешем
   - Когда начата установка
   - Тогда подтверждение источника (подпись или хеш) не прошло - плагин отклонён до выполнения кода; манифест, совместимость и граф проверяются до выполнения кода
2. [FR-CH-3023] [UC-SECURITY-TRUST-3001#3] [UC-SECURITY-TRUST-3001#3а] [UC-SECURITY-TRUST-3001#3б]
   - Дано плагин с правами `process`, `ui.lock` и `net: ["config:baseUrl"]`
   - Когда окно согласия показывает права
   - Тогда имя, версия, источник и права теми же строками, что «Плагины Cyborg»: «полный доступ через программу», «может закрыть окно Cyborg», «хост из настройки baseUrl: <значение>»
3. [FR-CH-3023] [UC-SECURITY-TRUST-3001#4] [UC-SECURITY-TRUST-3001#4а]
   - Дано человек не подтвердил или отказался
   - Когда установка завершается
   - Тогда плагин не ставится, данные не затронуты
4. [FR-CH-3023] [UC-SECURITY-TRUST-3001#6а]
   - Дано плагин правит `baseUrl` на новый хост
   - Когда смена значения поля хоста
   - Тогда новый хост требует подтверждения человека
5. [FR-CH-3024] [UC-SECURITY-TRUST-3001#7а]
   - Дано новая версия плагина расширяет права
   - Когда версия появляется
   - Тогда не включается до повторного согласия
6. [FR-CH-3022] [UC-SECURITY-TRUST-3001#5]
   - Дано плагин в `Compartment` вызывает `require('node:fs')`, `child_process`, `fetch`, подменяет компонент пути ссылкой
   - Когда код нарушителя выполняется
   - Тогда обход не работает, выход за права - `PermissionDenied` и запись `denied`, подмена компонента между проверкой и операцией не выводит операцию из области
7. [FR-CH-3021]
   - Дано границы, которые ядро не закрывает
   - Когда окно описывает права и агента
   - Тогда `process`, `pty` - «полный доступ через программу», `ui.lock` - «может закрыть окно Cyborg» и замок закрывает экран, а не данные; `shell` предупреждает об исполнении кода открытого документа; граница агента предупреждает, что внешний текст попадает в контекст агента без фильтра
