# ST-1005 Выгрузка и откат регистраций без перезапуска окна

Как человек, управляющий плагинами, я хочу выгружать и загружать плагин без перезапуска окна, чтобы после выгрузки от плагина ничего не оставалось.

Нормы: FR-CH-1006, FR-CH-1007. Сценарии: UC-AUTHOR-KIT-7001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-1006]
   - Дано плагин зарегистрировал контракт, команду, подписку, наблюдение `fs.watch`, сервер `serve`, диалог, `process.run` с потомками и запрос `net.fetch`
   - Когда плагин выгружен, хост упал или активация сорвалась
   - Тогда все регистрации сняты, в реестрах ядра записей плагина нет, потомки `process.run` завершены, запрос прерван
2. [FR-CH-1006]
   - Дано подписка плагина А на контракт плагина Б
   - Когда уходит любая из двух сторон
   - Тогда ядро снимает подписку
3. [FR-CH-1007]
   - Дано плагин-поставщик, его потребитель через `requires` и потребитель через `optional`
   - Когда человек выгружает поставщика
   - Тогда выгружаются поставщик и потребитель через `requires` в обратном порядке активации; потребитель через `optional` остаётся и получает `onChange`; окно не перезапускалось
4. [FR-CH-1007]
   - Дано хост, где остался один плагин
   - Когда плагин выгружен
   - Тогда хост погашен; загрузка поднимает код в новом процессе
5. [FR-CH-1007]
   - Дано плагин выгружен человеком
   - Когда сторож или включение соседа пытаются его поднять
   - Тогда плагин остаётся выгруженным
6. [FR-CH-1007] [UC-AUTHOR-KIT-7001#8а]
   - Дано файл настроек, в котором `plugins.enabled` изменён без перезапуска
   - Когда ядро читает файл
   - Тогда убранные плагины выключены, вернувшиеся включены; плагин, которого не было в графе при запуске, ждёт перезапуска с записью в окне
