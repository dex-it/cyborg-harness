# ST-1004 Человек видит причину сбоя и включает плагин снова

Как человек, у которого плагин отказал, я хочу видеть состояние и причину словами и включать плагин одним действием, чтобы не перезапускать приложение.

Нормы: FR-CH-1003, FR-CH-1016. Сценарии: UC-PLUGIN-HOST-1001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-1003] [UC-PLUGIN-HOST-1001#2] [UC-PLUGIN-HOST-1001#3]
   - Дано плагин-поставщик отказал при активации; рядом потребитель через `requires` и потребитель через `optional`
   - Когда ядро активирует остальные плагины
   - Тогда потребитель через `requires` не запускается с записью «поставщик не активен», потребитель через `optional` работает без него
2. [FR-CH-1016] [UC-PLUGIN-HOST-1001#5] [UC-PLUGIN-HOST-1001#6]
   - Дано плагин снят сбоем при активации, потребители через `requires` не запустились
   - Когда человек нажимает «Включить снова» в «Плагины Cyborg»
   - Тогда плагин активирован, следом активированы потребители, не запустившиеся из-за него; состояние и причина показаны словами
3. [FR-CH-1016]
   - Дано плагин выключен сторожем после трёх зависаний
   - Когда человек вызывает «Включить снова»
   - Тогда плагин включён тем же вызовом
4. [FR-CH-1016]
   - Дано имя плагина, которого нет
   - Когда вызвано «Включить снова»
   - Тогда отказ с причиной, остальные плагины не затронуты
