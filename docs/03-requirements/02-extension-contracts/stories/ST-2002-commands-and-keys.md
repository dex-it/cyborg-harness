# ST-2002 Команды, сочетания клавиш и пункты меню объявляются плагином

Как разработчик поставки, я хочу объявлять команды, сочетания и пункты меню в манифесте, чтобы функции были доступны одинаково из каркаса и любого фрейма.

Нормы: FR-CH-2004, FR-CH-2024, FR-CH-2025. Сценарии: UC-AUTHOR-KIT-7001, UC-EXTENSION-CONTRACTS-2001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-2004] [UC-EXTENSION-CONTRACTS-2001#2]
   - Дано команда в манифесте исполнителя со схемой аргументов
   - Когда команду зовут из вида, сочетания или другого плагина с аргументом не по схеме
   - Тогда ядро отклоняет вызов до обработчика; необъявленная команда отклоняется; чужой хост команду не перехватывает
2. [FR-CH-2004]
   - Дано команда `a.b.run` объявлена манифестами двух плагинов `a` и `a.b`
   - Когда ядро загружает плагины
   - Тогда команду не получает ни один, кроме встроенного; сторонний отвергнут (`rejected`, причина `command`); вид и клик по уведомлению запускают только команду своего плагина (`Kernel.runOwn`)
3. [FR-CH-2004]
   - Дано сочетание в манифесте, привязанное к команде без обязательных аргументов
   - Когда человек нажимает его из каркаса и из `<iframe>`
   - Тогда команда запускается одинаково: ядро перехватывает сочетание в главном процессе до страницы
4. [FR-CH-2004] [UC-AUTHOR-KIT-7001#2г]
   - Дано два плагина занимают одно сочетание
   - Когда ядро загружает плагины
   - Тогда видна запись `key-conflict`; побеждает встроенный, между равными - первый по id; победитель выгружен - сочетание идёт окну; запись `plugins.keybindings` воркспейса побеждает запись пользователя
5. [FR-CH-2024] [FR-CH-2004]
   - Дано плагин регистрирует сочетание `ctx.keys.register` с условием из списка `repeat`, `dialog`, `visible`, `input`
   - Когда плагин выгружается или регистраций больше 128
   - Тогда сочетание снято при выгрузке, падении хоста и откате; сверх 128 регистраций на плагин - отказ; занять динамически сочетание окна или меню приложения нельзя (`CommandConflict`)
6. [FR-CH-2025]
   - Дано плагин объявил `contributes.menus` в меню `tools` со своей командой и булевым членом контракта для `enabled`
   - Когда плагин выключен или пытается убрать пункт ядра
   - Тогда пункт выключенного плагина остаётся недоступным; пункты ядра убрать нельзя; сочетание пункта занимает единый реестр сочетаний
