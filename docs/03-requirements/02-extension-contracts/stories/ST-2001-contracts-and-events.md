# ST-2001 Плагины связываются контрактами по объявлению, без общей шины

Как разработчик поставки, я хочу, чтобы плагины давали и брали возможности только по объявлению в манифесте, не зная друг друга, чтобы новый плагин не требовал правки соседей.

Нормы: FR-CH-2001, FR-CH-2002, FR-CH-2005, FR-CH-2026, FR-CH-2027. Сценарии: UC-EXTENSION-CONTRACTS-2001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-2001] [UC-EXTENSION-CONTRACTS-2001#2] [UC-EXTENSION-CONTRACTS-2001#3]
   - Дано плагин объявил `provides` одного контракта и `requires` другого; тип контракта есть в карте `Contracts` пакета `@cyborg-harness/contracts`
   - Когда потребитель берёт контракт через `ctx.contracts`
   - Тогда потребитель получает `Remote<T>` с асинхронными методами; поставщик не знает потребителей, потребитель не знает поставщика
2. [FR-CH-2001]
   - Дано плагин попытался отдать или взять контракт, не объявленный в манифесте
   - Когда плагин вызывает `ctx.contracts`
   - Тогда необъявленное не отдаётся и не берётся
3. [FR-CH-2001]
   - Дано контракт из `requires`, которого поставщик не отдал, и контракт `optional` без поставщика
   - Когда потребитель обращается к ним
   - Тогда `requires` даёт `Unavailable`, `optional` даёт `undefined`; `consumes` отдаёт всех поставщиков списком
4. [FR-CH-2001]
   - Дано метод контракта зовёт плагин, не связанный графом с поставщиком, или плагин из другого хоста
   - Когда вызов доходит до ядра
   - Тогда вызов отклонён: метод зовёт только связанный графом потребитель из своего хоста
5. [FR-CH-2002] [UC-EXTENSION-CONTRACTS-2001#4б]
   - Дано аргумент или результат вызова содержит функцию вне подписки
   - Когда вызов идёт через границу
   - Тогда ответ `NotCloneable`
6. [FR-CH-2002]
   - Дано потребитель подписался на событие контракта (`sessions.onChange`) и получил `Disposable`
   - Когда уходит либо потребитель, либо поставщик, либо хост поставщика падает
   - Тогда ядро снимает подписку; вызов колбэка от хоста, который подписку не обслуживает, отброшен; общей шины событий нет
7. [FR-CH-2002]
   - Дано события окна и системы (фокус, сон и пробуждение, блокировка экрана, простой, завершение) и один упавший слушатель
   - Когда событие приходит подписчикам `ctx.window` и `ctx.system`
   - Тогда соседний слушатель получает событие; `onBeforeQuit` ядро ждёт не дольше бюджета
8. [FR-CH-2026]
   - Дано потребитель начал вызов контракта
   - Когда потребитель отменяет вызов
   - Тогда отмена доходит до поставщика
9. [FR-CH-2027]
   - Дано главная часть плагина и его вид
   - Когда обмениваются данными по каналу ядра
   - Тогда граница клонирования та же, что у контрактов; модальное окно плагина открывается через слой окна
10. [FR-CH-2005] [UC-EXTENSION-CONTRACTS-2001#2а]
   - Дано плагину нужен чужой документ или диалог
   - Когда плагин вызывает команду или член контракта владельца
   - Тогда владелец сам показывает свой UI и возвращает данные; чужой UI в вид не встраивается
