# decision-log фичи 02 - контракты, доступ и UI плагинов

Решения составителя по запросу владельца (2026-11-02), сверенные 2026-11-05 с [SAD](../../04-architecture/design/sad.md) и кодом. Исход «открыто» - допущение, принятое за владельца; «заменено» и «снято» - решение пересмотрено SAD, новое устройство названо в основании.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Семь точек расширения; восьмая - только новым ADR | Широкий API сразу | Заменено: контракты в манифесте с проверкой графа до запуска кода, набора точек нет ([SAD, раздел 7](../../04-architecture/design/sad.md#7-расхождения-с-первой-редакцией-пакета)) | заменено |
| D-02 | Три режима событий: observe, waterfall, guard | Только observe; шесть режимов dsh | Снято: шины событий нет, событие - подписка в контракте владельца ([SAD, раздел 4](../../04-architecture/design/sad.md#4-взаимодействие-плагинов)) | снято |
| D-03 | Хуков «ядро спрашивает плагин» с локом нет; единственный guard - `session.start` | Хук как `message.dispatch` bb | Хуков нет, guard-событий тоже нет. `guard` в `provides` теперь значит другое - право вызывающего на аргумент члена (`via-contract`) | действует без guard-событий |
| D-04 | Контракт агента - pty-first; процесс держит ядро | SDK как основа; ACP как основа | ADR-CH-0004; поставщик `cyborg.agent` описывает запуск, pty запускает потребитель по своему праву, процесс держит ядро ([SAD, 3.6](../../04-architecture/design/sad.md#36-ресурсы-дольше-плагина-pty)) | действует |
| D-05 | Второй поставщик агента - до стабилизации контракта | Стабилизировать по одному агенту | Сделано: `agent-shell` в playground проходит общий набор с `agent-claude-code` (`playground/test/agents.test.ts`) | выполнено |
| D-06 | Вклад в системный промпт - waterfall `session.prompt` | Правка аргументов запуска плагинами | Заменено: контракт `cyborg.session-prompt` кратности many ([SAD, раздел 5](../../04-architecture/design/sad.md#5-пример-базовая-часть)) | заменено |
| D-07 | Проверка аргументов - свой маленький помощник | zod | Аргументы команд - схема манифеста (`core/src/wire.ts`), разделы - своё подмножество JSON Schema (`core/src/json-schema.ts`); зависимостей нет | действует |
| D-08 | Диалоги - сервис ядра, а не слот | Диалог как слот | `ctx.dialogs.show` в слое окна ядра (`core/src/window-layer.ts`) | действует |
| D-09 | Единый реестр сочетаний, проверка при загрузке | Ручной список занятых | Сочетания в манифесте, конфликт виден при загрузке ([SAD, 3.9](../../04-architecture/design/sad.md#39-системные-клавиши-и-события)) | действует |
| D-10 | L2: отдельный процесс (`utilityProcess`), изолированное окно для интерфейса | Один процесс с полным доверием; `vm` | Заменено: все главные части - в хостах `utilityProcess` с этапа 1, UI каждого плагина - в своём `<iframe>`, изоляция доступа - `Compartment` этапа 2 ([SAD, раздел 6](../../04-architecture/design/sad.md#6-этапы)) | заменено |
| D-11 | Какой второй настоящий агент проверит контракт | - | Контракт проверяет `agent-shell`; второй настоящий агент - выбор владельца | **открыто, нужен ответ владельца** |
