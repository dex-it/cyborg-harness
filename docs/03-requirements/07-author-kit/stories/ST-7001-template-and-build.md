# ST-7001 Автор начинает с шаблона и собирает плагин с проверкой состава

Как автор плагина вне поставки, я хочу скопировать шаблон и собрать плагин одной командой, чтобы получить рабочий бандл без правок и без чужих модулей внутри.

Нормы: FR-CH-7001, FR-CH-7002, FR-CH-7010. Сценарии: UC-AUTHOR-KIT-7001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-7001] [UC-AUTHOR-KIT-7001#1]
   - Дано каталог `templates/plugin`, скопированный под своим именем
   - Когда автор запускает `checkPlugin` и сборку
   - Тогда каталог проходит `checkPlugin` без нарушений и собирается без правок; в нём `manifest.json`, главная часть и пример: вид, команда, контракт, раздел `config` со схемой, тест на `@cyborg-harness/testing`, `tsconfig.json` и `package.json` автора; генератора `cyborg-plugin new` нет
2. [FR-CH-7002] [UC-AUTHOR-KIT-7001#6]
   - Дано плагин с npm-зависимостью в главной части
   - Когда автор запускает `cyborg-plugin build`
   - Тогда перед сборкой прогоняется `checkPlugin`, npm-зависимости ложатся внутрь бандла; вид собирается в ESM-модуль рядом с файлами своего origin, карты исходников рядом
3. [FR-CH-7002] [UC-AUTHOR-KIT-7001#6а] [UC-AUTHOR-KIT-7001#4б]
   - Дано в составе бандла есть `node:*`, `electron` или чужой плагин
   - Когда автор запускает сборку
   - Тогда сборка падает с перечнем нарушений, бандл не создаётся; плагин с npm-зависимостью без бандла не загрузится вовсе
4. [целевое поведение] [FR-CH-7010] [UC-AUTHOR-KIT-7001#2] [UC-AUTHOR-KIT-7001#2б]
   - Дано шаблон и сборка плагина, собранного под API 1.5; манифест с диапазоном `^1`
   - Когда автор запускает сборку и `checkPlugin`
   - Тогда в `engines.cyborg` нижней границей стоит минорная версия, под которую собран плагин (`^1.5`); `checkPlugin` предупреждает о диапазоне без нижней границы
