# ST-7004 Автор проходит путь по руководству, не читая код ядра

Как автор плагина со стороны, я хочу пройти путь от шаблона до окна по руководству, чтобы не открывать код ядра и не задавать вопросов, ответ на которые есть только в нём.

Нормы: FR-CH-7006, FR-CH-7007, FR-CH-7008, NFR-CH-1008. Сценарии: UC-AUTHOR-KIT-7001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-7006] [UC-AUTHOR-KIT-7001#1] [UC-AUTHOR-KIT-7001#9]
   - Дано руководство `docs/guide/authors/` под API 1.0
   - Когда автор проходит шаги пути (шаблон, манифест, главная часть, тесты, сборка, `checkPlugin`, установка в каталог пользователя)
   - Тогда каждый шаг выполняется без чтения кода ядра; всё, что описано как существующее, существует в выпуске
2. [FR-CH-7006] [FR-CH-7008] [UC-AUTHOR-KIT-7001#1а]
   - Дано автор не нашёл ответа в руководстве и справочниках, ответ есть только в коде ядра
   - Когда автор задаёт вопрос
   - Тогда вопрос фиксируется в трекере репозитория под отдельной меткой, число таких вопросов считается по метке; ответ дописывается в руководство, автор возвращается к шагу, на котором остановился
3. [FR-CH-7007]
   - Дано страница руководства о видах
   - Когда читатель ищет границу доступности
   - Тогда руководство называет границу: доступность элементов `cy-*` держит ядро, доступность всего остального во виде - автор плагина
4. [NFR-CH-1008] [UC-AUTHOR-KIT-7001#1] [UC-AUTHOR-KIT-7001#9]
   - Дано человек вне команды на чистой машине с руководством и шаблоном выпуска
   - Когда за один заход собирает плагин с видом, командой, контрактом и разделом `config`
   - Тогда плагин собран и загружен, вопросов с ответом только в коде ядра - 0; обращение к коду ядра - неуспех
