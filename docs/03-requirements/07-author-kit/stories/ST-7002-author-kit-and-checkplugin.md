# ST-7002 Пакет объявлений и checkPlugin: типы, импорты, права словами

Как автор плагина вне репозитория ядра, я хочу проверить каталог плагина до загрузки, чтобы увидеть нарушения манифеста, импортов и прав раньше, чем плагин попадёт в приложение.

Нормы: FR-CH-1013, FR-CH-7005, FR-CH-7009. Сценарии: UC-AUTHOR-KIT-7001, UC-EXTENSION-CONTRACTS-2001. SRS - [srs.md](../srs.md).

## Критерии приёмки

1. [FR-CH-1013] [UC-AUTHOR-KIT-7001#3] [UC-AUTHOR-KIT-7001#4] [UC-EXTENSION-CONTRACTS-2001#4]
   - Дано плагин на `@cyborg-harness/contracts` со своим контрактом `acme.*`, который дополняет карту `Contracts` через `declare module`
   - Когда автор пишет главную часть
   - Тогда типы берутся из пакета объявлений; к ОС плагин ходит только через `ctx`
2. [FR-CH-1013] [UC-AUTHOR-KIT-7001#4б] [UC-EXTENSION-CONTRACTS-2001#4а]
   - Дано главная часть, импортирующая `node:fs`, `electron` или чужой плагин; вид, импортирующий npm-пакет
   - Когда проверяется правило импортов
   - Тогда главная часть пропускает только `@cyborg-harness/contracts`, свой пакет объявлений и свои модули (и npm-пакеты, если собирается `cyborg-plugin build`); виду разрешены ещё npm-пакеты; `node:*` и `electron` нарушение для обоих
3. [FR-CH-7005] [UC-AUTHOR-KIT-7001#2а] [UC-AUTHOR-KIT-7001#7]
   - Дано каталог плагина вне репозитория ядра с манифестом без `id` и ссылкой на несуществующий модуль вида
   - Когда автор запускает `checkPlugin(dir, options)` или `cyborg-plugin check`
   - Тогда манифест проверен целиком, ошибки идут строками «файл:строка: причина»; проверены `engines.cyborg`, точка входа, модули видов и файлы схем внутри каталога; права выведены словами; результат - структура и код возврата 1 с нарушениями, 0 без них
4. [FR-CH-7005] [UC-AUTHOR-KIT-7001#4б] [UC-AUTHOR-KIT-7001#7а]
   - Дано каталог с `import()` с вычисляемым путём и импортом чужого плагина
   - Когда автор запускает `checkPlugin`
   - Тогда оба случая - нарушения правила импортов; автор правит манифест (возврат к шагу 2) или код (возврат к шагу 4)
5. [целевое поведение][FR-CH-7009] [UC-AUTHOR-KIT-7001#7]
   - Дано член контракта или команда принимают путь и не объявляют `guard`
   - Когда автор запускает `checkPlugin`
   - Тогда проверка предупреждает о каждом таком члене и команде (для команды - право вызывающего)
6. [FR-CH-1013] [UC-EXTENSION-CONTRACTS-2001#6]
   - Дано новый встроенный плагин в репозитории
   - Когда разработчик прогоняет `npm test` (в нём проверка импортов `core/test/plugin-imports.test.ts`), `npm run typecheck`, `npm run lint`, `npm run smoke`
   - Тогда проверка импортов пропускает главной части только `@cyborg-harness/contracts` и свои модули, остальные гейты зелёные
