# Стратегия: идеи

Идея входит в корпус одним файлом `IDEA-NN-<слаг>.md`. Формат объявляет поле `format` в шапке (`one-pager`, затем `canvas`), обязательное поле одно - статус: `черновик`, `принято`, `отклонено`. Отклонённая идея остаётся в списке со своим статусом, чтобы её не обсуждали заново. Идея со статусом `принято` порождает продукт или фичу: бизнес-требования идут в [BRD](../01-product/brd.md), фичи - в [нормы](../03-requirements/README.md).
