Плагин не импортирует другой плагин и не знает, кто его поставщик. Связь идёт через ядро двумя способами: **контракт** - именованный набор методов с версией - и **команда** - вызов по имени.

## Контракт

Контракт состоит из имени, версии и типов. Типы лежат в пакете `@cyborg-harness/contracts` без логики; поставщик и потребитель импортируют оттуда один и тот же тип.

Манифест называет роли:

| Поле манифеста | Роль | Если поставщика нет |
|---|---|---|
| `provides` | плагин реализует контракт | - |
| `requires` | нужен ровно один поставщик | плагин не загружается |
| `optional` | один поставщик, если есть | плагин работает без него |
| `consumes` | все поставщики списком (кратность `many`) | список пуст |

```jsonc
// манифест потребителя
"requires": { "cyborg.agent-tool": "^1" },
"consumes": { "cyborg.session-prompt": "^1" }
// манифест поставщика
"provides": { "cyborg.session-prompt": "1.0" }
```

В коде потребитель получает контракт по имени и мажорной версии, а ядро выводит тип из карты контрактов:

```ts
const tools = ctx.contracts.all('cyborg.agent-tool', 1);   // Provider<Remote<AgentTool>>[]
ctx.subscriptions.add(ctx.contracts.onChange('cyborg.agent-tool', refresh));
```

Мажорная версия в `get` и `all` обязательна. Компилятор проверяет, что она есть в карте, а ядро - что она лежит в диапазоне из манифеста потребителя; иначе вызов получает `NotDeclared`.

## Как выглядит вызов

Для потребителя вызов одинаков, живёт поставщик в том же хосте или в другом. Правила границы:

- методы чужого контракта всегда асинхронные: `Remote<T>` превращает каждый метод в `Promise`;
- аргументы и результаты - данные, которые переживают `structuredClone`; функция, класс или `Map` отвечают `NotCloneable`;
- обратный вызов только один - подписка, которая возвращает `Disposable`; сам колбэк остаётся в хосте потребителя;
- при выгрузке или падении любой из сторон ядро снимает подписки само;
- метод ждёт ответа поставщика не дольше предела ядра, дальше вызывающему приходит `Timeout`.

Общей шины событий нет. Событие - часть контракта того, кто владеет предметом.

## Отмена запроса

Долгий запрос между плагинами можно отменить. Вызывающий отзывает запрос, поставщик получает сигнал отмены и прекращает работу, вызывающий получает отказ. Отменённый запрос не оставляет живых подписок. Запись отмены в API плагина описана в [руководстве по главной части](/authors/main-api/).

## Права через контракт

Поставщик, который по чужой просьбе читает или пишет путь, объявляет это в `provides` полем `guard`: какие аргументы члена - пути или ссылки на секреты. Ядро сверяет аргумент с правом **вызывающего** до передачи вызова. Отказ - `PermissionDenied` с записью `denied` и `reason: 'via-contract'`. Поставщик дальше работает своими правами, так что действует пересечение: право вызывающего поставщика не расширяет.

## Устаревшие члены

Член контракта с пометкой `@deprecated` живёт минимум до следующей мажорной версии. Ядро пишет в журнал, кто его вызывает, поэтому поставщик видит, когда можно выпускать новую мажорную версию. Пометку ядро берёт из манифеста поставщика, потому что типов TypeScript оно не видит: поле `deprecated` в `provides`, рядом с `guard`.

```json
"provides": { "demo.files": { "version": ["1.4", "2.0"], "deprecated": ["list"] } }
```

Когда плагин вызывает такой член, из главной части или из вида, в журнале появляется запись: кто вызвал, чей контракт, какой член. Повторы за 5 секунд склеиваются в одну запись со счётом, а записей всего не больше 1000. Вызов при этом не блокируется. Запись видна в окне «Плагины» у вызывающего и у поставщика.

## Команды

Команда - вызов по имени: «пусть сделает кто-нибудь». Плагин регистрирует обработчик через `ctx.commands.register`, остальные вызывают его через `ctx.commands.run`. Аргументы описывает манифест исполнителя, ядро сверяет их до обработчика, откуда бы ни пришёл вызов.

```jsonc
"commands": {
  "tabs.open": { "args": ["string"] },
  "acme.log":  { "args": ["string", "number?"] }
}
```

Виды аргументов: `string`, `number` (конечное), `boolean`, `array`, `strings`, `record`, `any` (не `undefined`). Необязательные - только в хвосте. Неизвестная команда отвечает `CommandNotFound`, дубль имени - `CommandConflict`. Вид плагина может запускать только команды своего плагина.

## Кто объявляет контракт

Контракт вклада объявляет владелец сущности: тот, кто рисует или хранит предмет. Вкладчик зависит от владельца, а не наоборот. Общий ресурс предметной области получает плагин-владелец с контрактом, а не место в ядре. Все 11 правил - в [модели контрактов](/concepts/contracts-model/).

## Пространства имён

| Пространство | Кто объявляет |
|---|---|
| `cyborg.*` | репозиторий Cyborg и пакет `@cyborg-harness/contracts`; доступно только встроенным плагинам |
| `acme.*` (по автору) | сторонний автор в своём пакете объявлений |

Сторонний пакет дополняет карту через `declare module '@cyborg-harness/contracts'`, ничего не меняя в самом пакете.
