Playground - приложение на Electron из репозитория. Оно подключает ядро так, как это делает любое приложение, и держит набор базовых и демонстрационных плагинов. Это самый быстрый способ увидеть хосты, сторож, права и виды в работе.

## Запуск

```bash
git clone https://github.com/dex-it/cyborg-harness.git
cd cyborg-harness
npm ci
npm start
```

`npm start` собирает стенд в `playground/dist` и открывает окно. Требования - на странице [Что нужно](/start/requirements/). Окно запоминает воркспейс; чтобы открыть другой файл или запуститься без воркспейса, передайте `--workspace=<файл>` или `--no-workspace`. Если плагин ломает запуск, `--safe-mode` (или «Перезапустить в безопасном режиме» в окне) поднимает окно без кода плагинов; режим переживает смену воркспейса и снимается пунктом «Выйти из безопасного режима». Плагины из каталога пользователя (`plugins/` в каталоге данных) читаются только при запуске с `--user-plugins` (`npm start -- --user-plugins`); флаг, как и безопасный режим, переживает смену воркспейса ([политика](/features/plugins/#каталог-пользователя-на-первом-этапе)). Повторный запуск при открытом окне режим не включает: окно получает фокус, а режим включается пунктом «Перезапустить в безопасном режиме».

## Что в окне

Слева - сессия агента, справа - вкладки.

| Вкладка | Что показывает |
|---|---|
| Плагины | Состояние каждого плагина, его хост, права словами; кнопки выключить, включить, уронить и повесить хост |
| Виды | Виды плагинов, каждый в своём `<iframe>` |
| Документы | Вкладки плагинов, которые переживают перезапуск |
| Сообщения | Журнал `ctx.log` и отказов команд |
| Журнал | Записи ядра: активация, отказы прав, падения хостов, конфликты сочетаний |
| Клавиши | Сводная таблица сочетаний и конфликты |

## Плагины стенда

Базовые плагины собирают рабочую сессию агента, демонстрационные показывают отдельные возможности.

| Плагин | Что показывает |
|---|---|
| `sessions` | Сессии агента во вкладках документов; потребитель контрактов `cyborg.agent`, `cyborg.agent-tool` и `cyborg.session-prompt` |
| `agent-claude-code` | Поставщик `cyborg.agent` для Claude Code: запуск, события, продолжение сессии |
| `agent-shell` | Второй поставщик `cyborg.agent` - агент без следов, только запуск и вывод |
| `session-isolation` | Вклад в системный промпт сессии |
| `next-actions` | Инструмент агента, который предлагает человеку кнопки под сессией |
| `pin-lock` | Замок окна с экраном `ui.overlay` и правом `ui.lock` |
| `echo` | Терминал в виде по билету pty, отказ права на чтение вне области |
| `chat`, `alice`, `bob` | Контракты: `requires`, `optional`, выгрузка поставщика и возврат |
| `later` | Ленивая активация по первой команде |
| `flaky` | Плагин, который падает: проверка сторожа и страйков |

## Что попробовать

1. **Выгрузить поставщика.** Выключите `chat`: вместе с ним снимется `alice`, потому что у неё чат в `requires`, а `bob` переживёт и переподпишется, когда чат вернётся.
2. **Вызвать отказ.** Запустите команду `echo.files` и посмотрите в журнале запись `denied` для чтения вне области.
3. **Уронить хост.** Нажмите «Уронить» или «Повесить» у плагина: сторож назовёт виновника, хост перезапустится за доли секунды, терминалы продолжат работать.
4. **Нажать сочетание.** `F2` вызывает команду, `Ctrl+Shift+L` (на macOS `Cmd+Shift+L`) закрывает окно замком. На вкладке «Клавиши» видно, у какого плагина какое сочетание и где они пересеклись.
5. **Пережить перезапуск хоста.** Терминал `echo` держит pty с `persist`: после падения хоста вид снова открывает тот же процесс и получает хвост вывода.

## Другие команды репозитория

| Команда | Что делает |
|---|---|
| `npm run demo -- all` | Прогоняет сценарии ядра в консоли без Electron; `-- --help` покажет список |
| `npm run smoke` | Дымовой тест окна: плагины, виды, клавиши, терминал |
| `npm run spike:hosts` | Замер хостов: память, цена вызова, пороги сторожа |
| `npm run spike:gateway` | Замер шлюза `ctx.os` и проверка бюджета: медиана трёх прогонов против `--budget=<мс>` и `--watch-budget=<мс>`, превышение - код выхода 1; трасса операций ядра включена, `--trace=off` даёт базу для сравнения |
| `npm run spike` | Замер фреймов: память и процессы на свой и общий origin |

:::note[Стенд не образец раскладки]
Раскладку окна playground выбрал под себя. Ядро не навязывает её: приложение расставляет виды по областям само ([Раскладка](/features/layout/)).
:::
