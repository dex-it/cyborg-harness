## Обязательное

| Что | Зачем |
|---|---|
| macOS или Linux | Проверено на macOS (Apple Silicon) и Linux; каждое изменение проходит CI на обеих системах |
| Node.js 24 и npm | Сборка и запуск; пакет `@cyborg-harness/core` объявляет `engines.node` под Node 24 |
| Electron 45 | Приложение, которое подключает ядро. Electron 45 несёт Node 24, на нём работают хосты плагинов |
| git | Чтобы взять репозиторий со стендом |

## Для сборки нативного модуля

Терминалы плагинов держит `node-pty` - нативный модуль. Его нужно собрать под вашу версию Electron: в стенде это делает `postinstall` (`electron-rebuild`), в приложении тот же шаг добавляете вы. Для сборки нужны средства компиляции вашей системы: Xcode Command Line Tools на macOS, компилятор и `make` на Linux.

## Для запуска без экрана

Стенд и дымовой тест открывают настоящее окно. На сервере без дисплея на Linux запускайте их под виртуальным дисплеем:

```bash
xvfb-run --auto-servernum npm run smoke
```

Если в системе нет песочницы Chromium, окну можно передать `--no-sandbox`: так запускается проверка в CI.

## Для автора плагина

| Что | Зачем |
|---|---|
| `@cyborg-harness/contracts` | Типы API плагина и карта контрактов |
| TypeScript | Главную часть и вид удобно писать на нём; Node 24 сам снимает типы с файлов вне `node_modules` |
| `@cyborg-harness/testing` | Тесты плагина без Electron |
| `cyborg-plugin` | Создать каталог плагина, проверить, собрать, упаковать |

Если главная часть остаётся на TypeScript без сборки, в ней допустим только стираемый синтаксис: без `enum` и параметров-свойств конструктора. Сборка командой `cyborg-plugin build` снимает это ограничение и добавляет зависимости внутрь файла.

## Что не поддерживается

:::caution[Границы]
- **Windows.** pty, наблюдение за файлами и замеры на Windows не проверялись; система не входит в области проверки.
- **Установка плагинов из внешнего источника.** Окна согласия, подпись и процесс на плагин с `--permission` относятся ко второму этапу изоляции. Сейчас плагины поставляются в составе приложения, а плагин от стороннего автора получает собственный хост.
- **Подписанные сборки.** Стенд запускается из исходников.
:::

Подробнее о том, что гарантирует граница хоста и чего она не гарантирует, - на странице [Границы доверия](/concepts/trust/). Сводная таблица систем и версий - в справке [Платформы](/reference/platforms/).
