---

Журнал плагинов - то место, где ядро объясняет, почему плагин не загрузился, остановился или получил отказ. Он виден в окне управления плагинами. Каждая запись относится к плагину (`pluginId`) или к хосту целиком. Записи описаны словами для человека, а поля ниже нужны тому, кто читает журнал программой.

## Записи по плагину

| Запись | Уровень | Когда пишется | Поля |
|---|---|---|---|
| `disabled` | инфо | Плагина нет в `plugins.enabled` | - |
| `not-found` | ошибка | Плагин включён, но не найден в каталогах плагинов | - |
| `invalid` | ошибка | Манифест не разобран | `errors` - список причин |
| `rejected` | ошибка | Граф контрактов отказал | `reasons` - см. ниже |
| `safe-mode` | предупреждение | Безопасный режим: код не запускается | - |
| `skipped` | предупреждение | Поставщик из `requires` не активен | `reason` |
| `config`, `state` | инфо или ошибка | Раздел не прошёл проверку или миграцию, либо плагин откатили | `result` - см. ниже |
| `waiting` | инфо | Ленивый плагин ждёт пробуждения | - |
| `activated` | инфо | Плагин поднят | `hostId`, `ms` - время запуска |
| `failed` | ошибка | Хост не запустился или `activate` упал | `hostId`, `error` |
| `deactivated` | инфо или предупреждение | Плагин снят; с ошибкой - предупреждение | `error?` |
| `unloaded` | инфо или предупреждение | Выключен человеком или вместе с поставщиком, которого требовал | `by`, `error?`, `keptPty?` |
| `revived` | инфо | Включён снова | - |
| `unhandled-rejection` | предупреждение | Промис плагина отклонён без обработчика; хост держится, плагину страйк | `error` |
| `switched-off` | ошибка | Выключен сторожем после череды сбоев: зависаний, падений, необработанных отклонений | `strikes`, `affects` |
| `denied` | предупреждение | Шлюз `ctx.os` отказал: вызов вне прав; с `reason: 'window'` - окно не пустило вид на чужой адрес | `method`, `detail`, `reason?`, `repeats?` |
| `pty-expired` | предупреждение | Терминал без владельца не взят через `attach` за льготное время и завершён: после падения хоста или после активации плагина, в том числе вернувшегося к оставленным человеком процессам | `id`, `program`, `graceMs` |
| `key-conflict` | предупреждение | Сочетание уже занято другим плагином | `key`, `command`, `winner` |
| `host-isolated` | предупреждение | Сторонний плагин назван в группе, но получил отдельный хост | `group`, `hostId` |
| `host-own-grouped` | предупреждение | Плагин поставки просит `"host": "own"`, а группа `plugins.hosts` сажает его к соседям: действует группа | `group`, `neighbours` |

## Записи по хосту и настройкам

У этих записей нет `pluginId`, они касаются хоста или записей `plugins.keybindings`.

| Запись | Уровень | Когда пишется | Поля |
|---|---|---|---|
| `host-down` | предупреждение | Хост завис или упал | `hostId`, `reason` (`hang` или `crash`), `culprits`, `plugins`, `affects` |
| `host-restart` | инфо | Хост перезапускается | `hostId`, `plugins` |
| `host-abandoned` | ошибка | Хост падает без виновника несколько раз подряд и больше не перезапускается | `hostId`, `failures`, `plugins` |
| `key-ignored` | предупреждение | Привязка `plugins.keybindings` не применена | `key`, `command`, `reason` |

## Причины отказа графа (rejected)

| Причина | Смысл |
|---|---|
| `duplicate` | Второй плагин с тем же id |
| `engines` | `engines.cyborg` не принимает версию API; поля `range` и `api` |
| `missing` | Нет поставщика для `requires`; поля `contract`, `range` |
| `ambiguous` | Несколько поставщиков при кратности `one`; поля `contract`, `providers` |
| `cycle` | Цикл зависимостей; поле `members` |
| `reserved` | Сторонний плагин занял пространство поставки (`cyborg.`): `what` - `id` или `provides`, поля `name`, `prefix` |

Отказ каскадом переходит на плагины, которые требовали отказавшего.

## Результат раздела (config, state)

| Статус | Смысл |
|---|---|
| `ok` | Раздел прочитан, `migrated` называет слои, где выполнена миграция |
| `newer` | Версия раздела выше известной плагину: похоже, плагин откатили. Данные не тронуты |
| `migrate-error` | `migrate` бросил исключение; поля `layer`, `from`, `error` |
| `invalid` | Значение не прошло схему или `validate`; `errors` - список |

## Отказы шлюза: denied

Поле `method` называет вызов (`fs.readText`, `config.set`, `ui.lock` и другие), `detail` - причину. `reason: 'via-contract'` означает, что право проверялось у вызывающего через `guard` поставщика. `reason: 'command-callers'` - главная часть плагина позвала чужую команду, которую исполнитель не открыл плагинам (`callers`); `method` - имя команды, запись лежит у вызывающего. `reason: 'window'` с `method: 'navigate'` - вид пытался увести свой или чужой фрейм либо окно с адреса плагина; в `detail` - адрес, обрезанный до 200 символов. Одинаковые отказы одного плагина за пять секунд склеиваются: первый пишется сразу, повторы - одной записью с полем `repeats`. В журнале хранится не больше тысячи записей `denied`; при переполнении уходит старейший отказ самого шумного плагина, так что поток отказов одного плагина не вытесняет чужие. Прочие записи не вытесняются: из них выводится состояние плагинов.

Значения секретов в журнал не попадают.

## Состояние плагина по журналу

Состояние вычисляется по последней записи, меняющей его. Записи `key-conflict`, `key-ignored`, `denied`, `unhandled-rejection`, `pty-expired`, `host-isolated` и `host-own-grouped` о работе плагина ничего не говорят и состояние не меняют.

| Запись | Состояние | «Включить снова» |
|---|---|---|
| `activated` | Работает | - |
| `waiting` | Ждёт | - |
| `disabled` | Выключен в настройках | - |
| `host-down`, `host-restart`, `revived` | Перезапускается | - |
| `switched-off`, `failed`, `skipped`, `host-abandoned` | Остановлен | Есть |
| `unloaded` (выгружен сам) | Остановлен | Есть |
| `unloaded` (вместе с поставщиком), `invalid`, `not-found`, `rejected`, `safe-mode`, `config`, `state`, `deactivated` | Остановлен | Нет: причина в манифесте, настройках или у поставщика |

## Уровни

- **инфо:** `activated`, `waiting`, `disabled`, `revived`, `host-restart`; `unloaded` и `deactivated` без ошибки.
- **предупреждение:** `denied`, `key-conflict`, `key-ignored`, `safe-mode`, `skipped`, `unhandled-rejection`, `pty-expired`, `host-down`, `host-isolated`, `host-own-grouped`; `unloaded` и `deactivated` с ошибкой.
- **ошибка:** все остальные, а также `config` и `state`, если статус не `ok`.
