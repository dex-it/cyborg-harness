description: "Какие системы поддерживает ядро, чем отличаются macOS и Linux и что с Windows."
---

Ядро рассчитано на macOS и Linux, Node 24 и Electron 45. Обе платформы проверяются в CI на каждое изменение; Windows не поддерживается.

| | macOS | Linux | Windows |
|---|---|---|---|
| Статус | поддерживается | поддерживается | не поддерживается |
| Проверка в CI | `macos-latest` | `ubuntu-24.04` | нет |
| Дымовой тест окна | `node playground/scripts/smoke.mjs` | `xvfb-run --auto-servernum node playground/scripts/smoke.mjs --no-sandbox` | нет |
| Замеры хостов и фреймов | Apple M1 Pro, Electron 45.2.2, Node 24.22.2 | Linux, Electron 45 | нет |
| Клавиша `CmdOrCtrl` | `Cmd` (внутри - `Meta`) | `Ctrl` | - |
| Хранилище секретов | `safeStorage` | `safeStorage`, нужен keyring ОС | - |
| Память в замерах | `footprint` | PSS из `/proc` | - |

## macOS

- Сочетание `CmdOrCtrl` превращается в `Cmd`. Нажатия настоящей клавиатурой проверены: сочетания плагинов, `F2` и `F6` с `Shift+F6` срабатывают, а ядро забирает нажатие до вида, так что в поле вида ничего не печатается.
- Память в замерах считается по физическому следу процесса (`footprint`), а на Linux по PSS. Это разные меры: цифры двух платформ нельзя вычитать друг из друга, их сравнивают как порядок величины.
- Хост плагина стоит около 27 МБ (footprint), и десять плагинов в одном хосте стоят как один: цена - процесс, а не плагин. Вид во фрейме со своим origin добавляет 22-34 МБ.
- Вызов через границу хоста быстрее, чем на Linux: p50 около 0,05 мс для 64 байт и около 0,13 мс для 64 КиБ из главного процесса в хост.
- На macOS нельзя проверять сочетания, посылая символ клавишей `keystroke`: он зависит от раскладки. В замерах нажатия идут по физическому коду клавиши, как это делает и ядро.

## Linux

- В CI дымовой тест идёт под виртуальным дисплеем (`xvfb-run`) и с флагом `--no-sandbox`. На рабочей машине, где настроена песочница Chromium, флаг не нужен.
- Хранилище секретов опирается на шифрование ОС. Без него (нет keyring) вызовы `ctx.os.secrets` получают `Unavailable`: значение не пишется открытым текстом. Автор плагина учитывает это в [рецептах](/authors/recipes/).
- Хост стоит около 34 МБ PSS сверх первого (около 56 МБ для первого). Вид во фрейме со своим origin добавляет около 13 МБ PSS.
- Перехват сочетаний при фокусе во фрейме подтверждён настоящим вводом X11.

## Windows

Windows не поддерживается и не проверялся: ни замеров хостов и фреймов, ни псевдотерминала `node-pty`, ни сочетаний, ни CI. В коде есть отдельные ветки для `win32` (сигналы процессов, отсоединённый запуск), но они не доказаны. Включение Windows в область ядра - отдельное решение владельца, и пока оно не принято, ни одна возможность на нём не обещана.

:::caution[Не рассчитывайте на Windows]
Плагин, который запускает программы или терминал, пишите так, чтобы он не предполагал пути и оболочки Windows. Манифест и контракты от платформы не зависят, но права `process` и `pty` называют конкретную программу, а её наличие и путь на разных системах разные.
:::

## Что общее

- Поведение ядра, манифест, контракты и API плагина одинаковы на обеих платформах: различаются только клавиша-модификатор, хранилище ключей ОС и числа замеров.
- Версии, под которые собирается и проверяется ядро: Node 24 (его несёт Electron 45) и Electron 45. Подробнее о требованиях - в [Требования](/start/requirements/).
- Числа в замерах - порядок величины для планирования, а не обещание: на общих раннерах CI задержки шумят, память стабильнее.
