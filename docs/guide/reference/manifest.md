Манифест - файл `manifest.json` в каталоге плагина. Ядро читает его до запуска кода. Незнакомое поле - отказ с именем поля; исключение - `$schema` для редактора. Все ошибки манифеста сообщаются сразу, одним списком.

Если `engines.cyborg` не принимает версию API ядра, причина отказа одна - версия API, даже когда в манифесте есть и другие ошибки.

## Поля верхнего уровня

| Поле | Тип | Обязательно | Ограничения |
|---|---|---|---|
| `$schema` | строка | нет | Адрес [схемы манифеста](#схема-манифеста) для редактора, ядро его игнорирует |
| `id` | строка | да | Шаблон `[a-z][a-z0-9-]*`, части через точку допустимы (`pin-lock`, `cyborg.files`). Идентификаторы `cyborg`, `cyborg.window` и `cyborg.workspace` заняты командами окна и ядра |
| `version` | строка | да | Версия плагина `x.y.z` |
| `engines.cyborg` | строка | да | Диапазон версий API плагинов, например `^1` |
| `provides` | объект | нет | Контракт - версия, список версий или `{ version, guard, deprecated }` |
| `requires` | объект | нет | Контракт - диапазон; кратность `one`, без поставщика плагин не загружается |
| `optional` | объект | нет | Контракт - диапазон; кратность `one`, без поставщика плагин работает |
| `consumes` | объект | нет | Контракт - диапазон; кратность `many` |
| `commands` | список или объект | нет | Имена команд плагина, со схемой аргументов или без |
| `keybindings` | список | нет | Сочетания клавиш, привязанные к своим командам |
| `contributes` | объект | нет | Вклады в окно; пока только `{ menus }` - пункты меню окна ([contributes](#contributes)) |
| `permissions` | объект | нет | Права; перечень - в [справочнике прав](/reference/permissions/) |
| `config` | объект | нет | `{ version, schema? }` - раздел настроек |
| `state` | объект | нет | `{ version, schema? }` - раздел состояния |
| `ui` | объект | нет | Виды, группа рендера, экран замка |
| `documents` | объект | нет | Типы документов плагина |
| `host` | строка | нет | Только `"own"` - просьба о собственном хосте |
| `activation` | строка | нет | Только `"lazy"` - ленивая активация |
| `lock` | объект | нет | Только `{ "onStart": true }`, требует права `ui.lock` |

## provides, requires, optional, consumes

- Имя контракта подчиняется тому же шаблону, что и `id`.
- Значение `provides` - строка версии, список версий (по одной на мажорную) или объект `{ "version": ..., "guard": ..., "deprecated": [...] }`. Две версии одной мажорной - ошибка.
- Значение `requires`, `optional`, `consumes` - диапазон версий: `*`, префикс версии (`1`, `1.2`), `^1.4` или `~2.3` по правилам npm.
- Один контракт не может быть одновременно в `requires` и `optional`, а контракт кратности `many` - в `requires` или `optional`.
- `guard` - словарь «член контракта - право и номер аргумента». Права: `fs.read`, `fs.write`, `shell`, `secrets.ref`. Аргумент задаётся номером (`0`) или путём `"0.path"`.

```jsonc
"provides": { "demo.files": { "version": "1.0", "guard": {
  "read": { "fs.read": 0 },
  "open": { "fs.read": "0.path" }
} } }
```

## commands

Список строк объявляет команды без аргументов; объект - со схемой.

```jsonc
"commands": {
  "tabs.open":  { "args": ["string"] },
  "acme.log":   { "args": ["string", "number?"] },
  "acme.trace": { "args": ["string"], "rest": "any" },
  "acme.sync":  { "args": ["record"], "callers": "plugins", "guard": { "fs.read": "0.path" } }
}
```

| Вид | Что принимает |
|---|---|
| `string`, `boolean`, `array` | Значение этого типа |
| `number` | Конечное число |
| `strings` | Массив строк |
| `record` | Объект |
| `any` | Любое значение, кроме `undefined` |

`?` в конце вида делает аргумент необязательным, но только в хвосте списка. `rest` - вид всех остальных аргументов; вместе с необязательными не допускается. Имя команды обязано начинаться с `<id>.`.

`callers` - кому открыта команда: `"user"` (по умолчанию) или `"plugins"`. Команду `user` не вызовет главная часть чужого плагина: `PermissionDenied` и запись `denied` с причиной `command-callers`. `guard` - объект `{ право: аргумент }`, права `fs.read`, `fs.write`, `shell`, `secrets.ref`, аргумент - номер или `"номер.поле"`; ядро сверяет значение с правом вызывающего. Разрешён только при `callers: "plugins"`. Подробно - [Контракты и команды](/features/contracts/#кому-открыта-команда).

## keybindings

```jsonc
"keybindings": [{ "key": "CmdOrCtrl+Shift+F", "command": "search.open" }]
```

- Команда объявлена в `commands` этого же плагина и не имеет обязательных аргументов.
- Запись сочетания: модификаторы `CmdOrCtrl`, `Ctrl`, `Alt`, `Shift`, `Meta` и клавиша - буква, цифра, `F1`-`F24`, `Enter`, `Escape`, `Space`, `Tab`, `Backspace`, `Delete`, `Insert`, `Home`, `End`, `PageUp`, `PageDown`, стрелки (`Up`, `Down`, `Left`, `Right`). Без модификатора допустимы только `F1`-`F24`.
- Одно сочетание в манифесте не повторяется.

## contributes

```jsonc
"contributes": {
  "menus": [
    {
      "id": "open",
      "menu": "view",
      "title": "Поиск",
      "command": "search.open",
      "order": 200,
      "accelerator": "CmdOrCtrl+Shift+F",
      "enabled": { "contract": "cyborg.projects", "major": 1, "member": "hasSelected" },
      "checked": { "contract": "cyborg.notifications", "major": 1, "member": "isOn" }
    }
  ]
}
```

Пункты меню окна, от одного до 32 на плагин. В `contributes` допустим только `menus`; незнакомое поле - отказ с именем поля (`contributes.<поле>`).

| Поле пункта | Обязательно | Ограничения |
|---|---|---|
| `id` | да | Имя пункта внутри плагина: строчные латинские буквы, цифры и дефис; не повторяется |
| `menu` | да | Одно из `workspace`, `view`, `tools`, `window`; подписи меню и их порядок задаёт приложение |
| `title` | да | Непустая строка до 80 символов |
| `command` | да | Своя команда из `commands` без обязательных аргументов |
| `order` | нет | Число; по умолчанию 1000. Пункты идут по меню, `order`, id плагина и id пункта |
| `accelerator` | нет | Сочетание в записи `keybindings`; не повторяется в плагине. Занимает место в едином реестре сочетаний: человек, команды окна и меню старше манифеста, проигравший виден в журнале |
| `enabled` | нет | Источник доступности. Нет поля - пункт доступен, пока работает плагин |
| `checked` | нет | Источник галочки. Есть поле - пункт с галочкой |

Источник - `{ "contract": "...", "major": 1, "member": "..." }`: булев метод контракта без аргументов, который плагин получает (`requires`, `optional`) или сам отдаёт (`provides`). Контракт из `consumes` не годится: поставщиков несколько. `major` должна входить в диапазон из манифеста.

Пункт неработающего плагина (не включён, выключен, вне графа, выгружен) не исчезает из меню, а недоступен. Ответ источника не `boolean`, ошибка или молчание дольше 2 с - пункт недоступен, в журнале запись `menu-source`. Пункт ленивого плагина доступен до активации, нажатие запускает плагин.

## config и state

`{ "version": 3, "schema": "./config.schema.json" }`. Версия - целое от 1. `schema` - путь `./<файл>.json` внутри каталога плагина, ссылка наружу - отказ.

## ui

| Ключ | Значение | Ограничения |
|---|---|---|
| `views` | Объект «имя вида - путь модуля или объект вида» (ниже) | Имя `[a-z][a-z0-9-]*`; путь `./.../файл.js` внутри каталога плагина; имя `overlay` занято |
| `overlay` | Путь модуля экрана замка | Только вместе с правом `ui.lock`; право без `overlay` манифест не примет |
| `group` | Строка | Рекомендация автора: группа рендера для видов плагина. Владелец переопределяет её в `plugins.uiGroups` |

Вид задают строкой (краткая запись) или объектом:

```json
"ui": { "views": {
  "tree": "./ui/tree.js",
  "sessions": { "module": "./ui/sessions.js", "area": "main", "order": 100, "title": "Сессии" }
} }
```

| Поле вида | Значение | По умолчанию |
|---|---|---|
| `module` | Путь модуля, как в краткой записи | обязательно |
| `area` | Род области: `sidebar` (боковая колонка), `main` (основная область с группой документов), `toolbar` (панель инструментов основной области), `popup` (всплывающий слой), `modal` (модальное окно по просьбе главной части: места в раскладке нет, документ модальным быть не может) | `sidebar` |
| `order` | Число: меньше - раньше | `1000` |
| `title` | Заголовок вида, непустая строка до 80 символов | нет |

Слой замка областью не задаётся: его объявляют как `ui.overlay`. Неизвестная область, нечисловой `order` и лишнее поле - ошибка манифеста с именем поля, например `ui.views.tree.area`.

Плагины из поставки занимают `order` от 0 до 1000 с шагом 100; ядро диапазон не проверяет.

## documents

Объект «тип документа - `{ "restorable": true, "area": "main", "order": 100 }`». Имя типа - как у вида; не больше 16 типов. `restorable` означает, что документ переживает перезапуск, а данные плагин отдаёт сам через `ctx.documents.save`. `area` (по умолчанию `main`) и `order` (по умолчанию `1000`) - как у вида. Ядро отдаёт область документа в `Kernel.layout` как есть, но вкладка документа по определению живёт в основной области; окна, которое расставляло бы документы по другим областям, пока нет.

## Остальные поля

| Поле | Что делает |
|---|---|
| `host: "own"` | Плагин просит собственный хост. Пользователь вправе переопределить; окно предупредит |
| `activation: "lazy"` | Плагин ждёт первой команды, сочетания, показа вида или потребителя своего контракта |
| `lock: { "onStart": true }` | Окно закрыто с первого кадра, плагин активируется сразу даже при `lazy`. Безопасный режим этого не делает |

## Схема манифеста

Файл [`manifest.schema.json`](https://github.com/dex-it/cyborg-harness/blob/master/contracts/manifest.schema.json) (JSON Schema draft-07) лежит в пакете `@cyborg-harness/contracts` и в репозитории в `contracts/`. Укажите его в первой строке манифеста, и редактор (VS Code и другие, понимающие `$schema`) подскажет поля, перечни значений и подчеркнёт ошибки формы:

```json
{
  "$schema": "./node_modules/@cyborg-harness/contracts/manifest.schema.json",
  "id": "hello",
  "version": "1.0.0",
  "engines": { "cyborg": "^1" }
}
```

Путь относительный: пакет контрактов уже стоит у автора (шаблон `templates/plugin` ссылается на схему так). Ядро поле `$schema` игнорирует.

**Схема не заменяет разбор.** Источник правды - `core/src/manifest.ts` (`parseManifest`); тест `core/test/manifest-schema.test.ts` держит их вместе: поля верхнего уровня схемы совпадают с ключами разбора, перечни (области, меню, права, виды аргументов) - с перечнями ядра, а манифесты `playground/plugins`, `core/examples/plugins` и `templates/plugin` получают от схемы и от `parseManifest` один итог. Схема проверяет форму каждого поля. Связи между полями проверяет только ядро (и `cyborg-plugin check`, который запускает тот же разбор):

| Схема это пропустит, ядро откажет |
|---|
| Команда вне пространства имён плагина (`commands` должны начинаться с `id` плагина и точки) |
| Привязка клавиши и пункт меню к команде, которой нет в `commands`, или к команде с обязательными аргументами; сочетание, которое не разбирается; повтор сочетания и `id` пункта |
| Контракт сразу в `requires` и `optional`; контракт кратности `many` в `requires` или `optional`; две версии одной мажорной в `provides` |
| Необязательный аргумент команды перед обязательным; `rest` вместе с необязательными аргументами; `guard` команды без `callers: "plugins"` или с аргументом не того вида |
| Право `ui.lock` без `ui.overlay`, `ui.overlay` и `lock.onStart` без права `ui.lock` |
| Источник `enabled` или `checked` пункта меню из контракта, которого нет в `requires`, `optional` и `provides`, или с мажорной версией вне диапазона |
| Диапазон `engines.cyborg`, не принимающий версию API ядра |

В обратную сторону схема строже ядра в одном месте: лишний ключ в описании команды (`commands.<имя>`) схема отклоняет, а ядро молча пропускает, так что опечатка вроде `calers` видна только редактору.

## Минимальный манифест

```json
{
  "id": "hello",
  "version": "1.0.0",
  "engines": { "cyborg": "^1" }
}
```
