Когда ядро отказывает плагину, оно бросает ошибку с полем `code`. Коды перечислены в типе `CoreErrorCode` пакета `@cyborg-harness/contracts`: их ровно двенадцать. Плагин сверяет код, а не текст сообщения: текст написан для человека и может меняться.

```ts
try {
  await files.read(path);
} catch (error) {
  if ((error as { code?: string }).code === 'PermissionDenied') {
    // права не хватило - показать причину, не повторять вызов
  }
}
```

## Таблица кодов

| Код | Что значит | Типичные причины | Что делать |
|---|---|---|---|
| `NotDeclared` | Плагин сделал то, чего не объявил в манифесте | контракт не в `provides`, `requires`, `optional` или `consumes`; команда не в `commands`; тип документа не в `documents`; раздел `config` или `state` не объявлен; мажорной версии нет в объявленном диапазоне | Добавить объявление в [манифест](/reference/manifest/) |
| `AlreadyProvided` | Контракт этой версии уже отдан | второй вызов `provide` с тем же контрактом и версией | Отдавать каждую версию один раз; снять прежнюю подписку |
| `Unavailable` | Нужной стороны сейчас нет | у контракта нет поставщика; плагин не активен или выгружен; хост не работает; ядро выгружается; включён безопасный режим; окно закрыто замком; в этой среде нет уведомлений, буфера обмена, диалога выбора, открытия в системе или псевдотерминала; хранилище секретов недоступно без шифрования ОС; нет источника секретов для схемы ссылки | Вызов можно повторить позже или подписаться на `onChange` контракта; для `optional` - обойтись без поставщика |
| `NotCloneable` | Аргументы или результат не переживают `structuredClone` | функция, класс, `Map` или `Symbol` в данных вызова | Передавать только данные; обратные вызовы - только через подписки |
| `Invalid` | Аргументы не прошли проверку | параметры не объект; поле не того типа; число вне границ; повторяющийся `id`; больше разрешённого числа слежений, серверов или документов; память вида больше 64 КБ; вид не из манифеста; неразобранный URL | Исправить вызов; сообщение называет метод и поле |
| `CommandNotFound` | Команды нет | имя не зарегистрировано ни одним плагином; команда объявлена, но владелец её не зарегистрировал | Проверить имя и то, что плагин-владелец активен |
| `CommandConflict` | Команда уже занята | два плагина объявили или зарегистрировали одно имя | Команды живут в пространстве `id` плагина: назвать по `id` |
| `HostGone` | Хост плагина остановлен посреди вызова | хост завис или упал; хост остановлен при выгрузке; ядро выгружено | Вызов не завершился; после перезапуска хоста повторить его можно, если действие безопасно повторить |
| `Timeout` | Ответ не пришёл вовремя | вызов члена контракта дольше срока; обработчик `serve.http` не ответил; сетевой хост не ответил за отведённое время | Сократить работу обработчика; длинное делать в фоне, а не в ответе |
| `Remote` | Ошибка по ту сторону канала без кода ядра | исключение в чужом обработчике, брошенное не ядром; ошибка запуска программы; ответ `net.fetch` больше предела или со статусом вне 200-599 | Читать сообщение: оно приходит от другой стороны |
| `PermissionDenied` | Права плагина не хватает | вызов `ctx.os` вне объявленных `permissions`; путь вне областей; программа не из списка; поле `config`, задающее хосты `net`, меняет не человек; хост `net` резолвится в локальный или частный адрес, которого право не называет; нет права `ui.lock` | Расширить [права](/reference/permissions/) в манифесте или отказаться от действия |
| `NotFound` | Запрошенного объекта нет | чужой или закрытый документ; билет терминала просрочен или уже использован; pty закрыт или завершён; сервер `serve.http` с таким `id` не найден; нет файла или каталога, на который указывает вызов | Не хранить `id` дольше жизни объекта |

## Как ошибка доходит до плагина

Вызов идёт через границу хоста, поэтому ошибка пересекает её в виде пары `code` и `message`. Принимающая сторона собирает из неё `CoreError` с тем же кодом. Если пришло что-то без этой формы, а также любое исключение, которое бросил не код ядра, плагин получает код `Remote`.

Вид получает отказы ядра в той же форме. Исключение составляют элементы `cy-*`: неверные пункты в `items` (пустой или повторяющийся `id`, не строка в подписи, больше 10 000 пунктов) бросают обычный `TypeError` с указанием места.

## Ошибка и запись журнала

Код ошибки видит тот, кто вызывал. Человек и автор видят то же в [журнале](/reference/journal/): отказ прав оставляет запись `denied` с методом и подробностью, падение хоста - `host-down`, отказ активации - `failed`. Поэтому на `PermissionDenied` достаточно один раз открыть журнал, чтобы увидеть, какого права не хватило.

:::tip[Не ловите всё подряд]
`Unavailable` и `HostGone` - состояния, которые проходят: плагин-поставщик перезапустился или ещё не включён. `NotDeclared`, `Invalid` и `PermissionDenied` сами не пройдут: повтор того же вызова даст тот же отказ. Различайте их.
:::
