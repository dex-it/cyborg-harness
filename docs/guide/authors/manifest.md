`manifest.json` лежит в каталоге плагина. Ядро читает его до запуска кода, поэтому конфликты сочетаний, недостающие поставщики и ошибки схем видны при загрузке, а не при первом нажатии. Сухая таблица всех полей - в справке [Манифест](/reference/manifest/); здесь - что и зачем объявлять.

## Минимальный манифест

```json
{
  "id": "greeter",
  "version": "1.0.0",
  "engines": { "cyborg": "^1" }
}
```

Три поля обязательны, остальные необязательны. Ключ `$schema` ядро принимает, чтобы редактор подсказывал поля; любое другое незнакомое поле - отказ с именем поля.

## Идентичность и совместимость

| Поле | Что значит | Ограничения |
|---|---|---|
| `id` | Имя плагина | Строчные латинские буквы, цифры и дефис, части через точку: `pin-lock`, `cyborg.files`. Нельзя имя, занятое командами окна ядра |
| `version` | Версия плагина | `x.y.z` |
| `engines.cyborg` | Диапазон версий API плагина, с которыми плагин работает | Диапазон semver; несовместимый - плагин не загружается, код не выполняется |

Если в манифесте есть ошибки и при этом `engines.cyborg` не принимает версию API ядра, причина одна: версия. Поле или значение новой версии API старое ядро не знает, и называть его ошибкой автора было бы неточно.

## Связи с другими плагинами

| Поле | Кратность | Если поставщика нет |
|---|---|---|
| `provides` | - | Плагин отдаёт контракт. Значение: версия `"1.0"`, список версий или `{ "version": ..., "guard": ... }` |
| `requires` | one | Плагин не активируется |
| `optional` | one | Плагин работает, поставщик может появиться позже |
| `consumes` | many | Плагин получает всех поставщиков списком |

В `provides` две версии одной мажорной недопустимы: `["1.4", "2.0"]` можно, `["1.0", "1.4"]` нельзя. Один контракт не может быть одновременно в `requires` и `optional`, а контракт кратности many - в `requires` или `optional`. Как это работает и что такое `guard` - на странице [Контракты](/authors/contracts/).

## Команды и сочетания

Команды - список имён или объект со схемой аргументов:

```json
"commands": {
  "acme.ping": {},
  "acme.log": { "args": ["string", "number?"] },
  "acme.trace": { "args": ["string"], "rest": "any" }
}
```

| Правило | Подробности |
|---|---|
| Пространство имён | Имя начинается с `id` плагина и точки |
| Виды аргументов | `string`, `number` (конечное), `boolean`, `array`, `strings`, `record`, `any` (всё, кроме `undefined`) |
| Необязательные | Суффикс `?`, только в конце списка |
| `rest` | Вид всех остальных аргументов; вместе с необязательными не разрешён |

Ядро сверяет аргументы со схемой до вызова обработчика, откуда бы ни пришла команда; несовпадение - `Invalid` с номером аргумента.

`keybindings` - список `{ "key", "command" }`. Запись сочетания вида `CmdOrCtrl+Shift+K` или `F5`; без модификатора допустимы только `F1`-`F24`. Команда должна быть объявлена в этом же манифесте и не иметь обязательных аргументов. Повтор сочетания внутри плагина - ошибка, а конфликт с другим плагином решается по правилам [Сочетаний](/features/keys/).

## Разделы config и state

```json
"config": { "version": 2, "schema": "./config.schema.json" },
"state": { "version": 1 }
```

`version` - целое от 1. `schema` - путь `./<файл>.json` внутри каталога плагина, без `..`. Ядро проверяет раздел по схеме до активации и после правки файла извне. Миграции и слои - [Настройки и состояние](/features/config-state/).

## Права

Поле `permissions` перечисляет, что плагин просит у ОС. Неизвестное право - ошибка манифеста, а не молчаливое «нет права». Перечень, области и маски - в справке [Права](/reference/permissions/), рецепты - в [Рецептах](/authors/recipes/).

## Виды, документы и окно

| Поле | Что значит |
|---|---|
| `ui.views` | Вид -> модуль `./путь/файл.js` внутри каталога плагина. Имя вида - строчные буквы, цифры и дефис; `overlay` занято. Каждый вид живёт в своём `<iframe>` |
| `ui.overlay` | Экран замка окна. Только вместе с правом `ui.lock`, и наоборот: право без экрана отклоняется |
| `ui.group` | Группа рендера, которой принадлежит вид; от неё зависит origin фрейма |
| `documents` | Типы документов `{ "<тип>": { "restorable": true } }`, не больше 16; `restorable` - документ переживает перезапуск |
| `lock` | `{ "onStart": true }` - окно закрыто с первого кадра. Только с правом `ui.lock` |
| `activation` | `"lazy"` - не при старте, а по первой команде, сочетанию, показу вида или потребителю |
| `host` | `"own"` - просьба о собственном хосте; пользователь вправе переопределить его группой в `plugins.hosts` |

Область окна, порядок и род вида, а также вклады в меню окна (`contributes.menus`) объявляются в манифесте и обрабатываются ядром до запуска кода. Форма записей меню и условных сочетаний относится к решениям проекта, перечисленным на странице [Решения](/development/decisions/).

## Точка входа

Главная часть - файл `index.mjs`, `index.js` или `index.ts` рядом с `manifest.json`. Его `default`-экспорт - `PluginModule`.

## Как ядро сообщает об ошибках

Разбор не останавливается на первой ошибке: `parseManifest` собирает все и отдаёт списком, а `cyborg-plugin check` печатает их строками `файл:строка: причина`. Плагин с ошибками не загружается, запись `invalid` в журнале перечисляет их.
