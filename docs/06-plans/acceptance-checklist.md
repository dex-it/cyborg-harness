# Чек-лист приёмки документов владельцем (P-11, #13)

> **Приёмка - решение владельца, а не составителя.** Этот файл не переводит ни один документ в `accepted`, не ставит подписей и не заменяет подтверждения владельца. Он собирает всё, что владелец должен прочитать и решить, и показывает, что уже сверено, чтобы приёмка заняла чтение, а не поиск.
