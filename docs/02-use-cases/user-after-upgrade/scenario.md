# Пользователь после обновления: данные целы, плагины работают

- **Актор:** человек, работающий в приложении на харнесе.
- **Цель:** обновить приложение или плагин и продолжить работу без потери настроек и данных.
- **Предусловия:** есть воркспейс в «Недавних»; у плагинов есть разделы `config` (файл пользователя и файл воркспейса) и `state`.
- **Требования:** BR-CH-002 ([BRD](../../01-product/brd.md)). Устройство - SAD [3.3](../../04-architecture/design/sad.md#33-версии-и-миграции), [3.10](../../04-architecture/design/sad.md#310-главный-конфиг-и-состояние), [5.3](../../04-architecture/design/sad.md#53-восстановление-сессий).

## Основной ход

1. Человек запускает новую версию; ядро открывает последний воркспейс из «Недавних» и берёт его замок.
2. Ядро читает манифесты и проверяет `engines.cyborg` каждого плагина до запуска кода.
3. Ядро разрешает граф контрактов и рисует каркас окна по манифестам.
4. Раздел `config` или `state`, версия которого ниже версии плагина, ядро до активации переводит `migrate(fromVersion, data)` плагина и сохраняет результат.
5. Ядро проверяет разделы по схемам из манифестов и активирует плагины в порядке графа.
6. Документы `restorable`-типов возвращаются вкладками; `sessions` показывает «Сессии прошлого запуска», и выбранная сессия поднимается через `resume` агента.
7. В «Плагины Cyborg» каждый включённый плагин активен или ждёт ленивой активации.

## Расширения

- **1а. Файл воркспейса старого формата `{projects, lastProjectId}`.** Ядро один раз переводит его в текущий формат и оставляет копию `<файл>.v1.bak`.
- **1б. Воркспейс уже открыт.** Второй запуск переводит фокус на открытое окно и завершается.
- **2а. Несовместимый `engines.cyborg`.** Плагин не загружается, код не выполнялся, причина в журнале; остальные работают.
- **3а. Поставщик сменил мажорную версию контракта, а потребитель просит старую.** Поставщик может давать две версии сразу. Если не даёт, потребитель через `requires` не загружается с причиной в журнале, а через `optional` работает без него.
- **4а. Версия раздела выше версии плагина (плагин откатили).** Плагин не активируется, раздел не трогается, причина в журнале.
- **4б. `migrate` упал или его нет.** Отказ только этому плагину, запись `migrate-error`.
- **5а. Раздел не прошёл схему (человек ошибся, правя файл руками).** Отказ только владельцу раздела. Если файл поправили во время работы, значение остаётся прежним, отказ - в журнале.
- **6а. Плагина-владельца типа документа нет.** Вкладка показывается недоступной, а не пропадает.
- **6б. У агента нет `capabilities.resume`.** В той же вкладке запускается новая сессия.

## Постусловия

Разделы плагинов прочитаны или не тронуты; каждый отказ назван в журнале; окно работает при любом исходе отдельного плагина.
