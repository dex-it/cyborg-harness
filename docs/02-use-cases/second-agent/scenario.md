# Подключение второго агента

- **Актор:** автор поставщика агента; человек, открывающий сессию.
- **Цель:** запускать другой CLI-агент рядом с Claude Code без правки ядра.
- **Предусловия:** у агента есть CLI; включены `sessions` (потребитель `cyborg.agent`) и хотя бы один поставщик агента.
- **Требования:** BR-CH-003 ([BRD](../../01-product/brd.md)). Устройство - SAD [раздел 5](../../04-architecture/design/sad.md#5-пример-базовая-часть) (`cyborg.agent`), [3.6](../../04-architecture/design/sad.md#36-ресурсы-дольше-плагина-pty); типы - `contracts/agent.ts`.

## Основной ход

1. Автор пишет плагин-поставщик `cyborg.agent`: `facts` (найдена ли программа, версия, `capabilities`: `resume`, `history`, `events`), `launch` (программа, аргументы, окружение, cwd), `watch` (события сессии), `ended` (уборка и причина выхода), `history`.
2. В манифесте объявляет `"provides": { "cyborg.agent": "1.0" }` и право `launch` на программу агента. Права `pty` поставщику не нужно: процесс запускает потребитель.
3. Проверяет поставщика по образцу общего набора тестов `playground/test/agents.test.ts`.
4. Человек включает плагин; `sessions` собирает всех поставщиков (кратность `many`) и показывает кнопку на каждого.
5. Человек нажимает кнопку. `sessions` спрашивает `facts`, получает описание запуска от `launch` с фрагментами промпта от поставщиков `cyborg.session-prompt` и запускает `ctx.os.pty.spawn` с `persist` и `describedBy`.
6. Ядро сверяет описание и с правом `pty` у `sessions`, и с правом `launch` у поставщика, запускает процесс и держит его у себя.
7. Терминал сессии открывается в виде `sessions` по билету; события `watch` (`cwd`, `session`, `activity`, `prompt`, `turnEnd`, `waiting`) приходят от поставщика.

## Расширения

- **1а. У агента нет следов (`capabilities.events: false`).** Работают запуск, вывод и ввод; подписка `watch` молчит, состояние «ждёт» не показывается. Так устроен `agent-shell` в playground.
- **3а. Сторонний автор хочет проверить поставщика тем же набором, что встроенный.** Общего набора тестов контракта пока нет ([SAD, открытый вопрос 10](../../04-architecture/design/sad.md#8-открытые-вопросы)).
- **5а. Программа не найдена (`facts.found: false`).** Сессия не создаётся, команда отвечает ошибкой «программа не найдена».
- **6а. Программы нет в праве `pty` у `sessions` или в праве `launch` у поставщика.** `PermissionDenied` и запись `denied` в журнале. Права пересекаются: поставщик не получает права потребителя, и программу нового агента должен разрешать манифест `sessions`.
- **7а. Процесс вышел с кодом 127.** `ended` называет причину `notFound`.
- **7б. Агент без `capabilities.resume`.** После перезапуска приложения сессия поднимается новой в той же вкладке.
- **7в. Агент не знает MCP.** Инструменты плагинов (`cyborg.agent-tool`) он пропускает; кнопок следующих шагов у его сессий нет.

## Постусловия

Ядро не менялось; Claude Code (`agent-claude-code`) работает рядом с новым агентом.
