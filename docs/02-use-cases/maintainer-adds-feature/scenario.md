# Автор встроенного плагина добавляет функцию

- **Актор:** разработчик поставки - команда, которая собирает приложение из встроенных плагинов.
- **Цель:** добавить возможность новым плагином, не трогая ядро и соседние плагины.
- **Требования:** BR-CH-001 ([BRD](../../01-product/brd.md)). Устройство - SAD [раздел 2](../../04-architecture/design/sad.md#2-что-есть-ядро), [раздел 4](../../04-architecture/design/sad.md#4-взаимодействие-плагинов), [6.1](../../04-architecture/design/sad.md#61-этап-1-ядро-без-изоляции-доступа).

## Основной ход

1. Разработчик заводит каталог плагина рядом со встроенными (в playground - `playground/plugins/<id>`): `manifest.json`, главная часть и, если нужен экран, вид в `ui/`.
2. В манифесте объявляет связи: какие контракты `cyborg.*` даёт и берёт, команды со схемой аргументов, сочетания, права, разделы `config` и `state` со схемой и версией.
3. Новый контракт `cyborg.*` добавляет в карту `Contracts` пакета `@cyborg-harness/contracts` - только типы, без логики. Поставщик и потребители знают друг друга только через него.
4. Пишет код только против `ctx` и импортирует только `@cyborg-harness/contracts` и свои модули.
5. Добавляет `id` в `plugins.enabled` поставки; плагин по умолчанию идёт в хост `builtin`.
6. Прогоняет гейты: `npm test` (в нём проверка импортов `core/test/plugin-imports.test.ts`), `npm run typecheck`, `npm run lint`, `npm run smoke`.
7. Ядро не правится: в его коде нет имён плагинов.

## Расширения

- **2а. Нужен чужой UI.** Плагин вызывает команду или член контракта владельца, а не встраивает его вид: владелец сам показывает свой документ или диалог и возвращает данные ([3.8](../../04-architecture/design/sad.md#38-изоляция-рендера)).
- **2б. Член контракта работает с путём по чужой просьбе.** Поставщик объявляет `guard` в `provides`; ядро сверяет аргумент с правом вызывающего до передачи вызова.
- **2в. Плагину нужен свой процесс.** `"host": "own"` в манифесте; человек вправе переопределить группировку, «Плагины Cyborg» покажут предупреждение.
- **3а. Контракт меняется несовместимо.** Выходит новая мажорная версия; поставщик может давать две сразу, член с `@deprecated` живёт минимум до следующей мажорной версии ([3.3](../../04-architecture/design/sad.md#33-версии-и-миграции)).
- **4а. Плагин импортирует `node:*`, `electron` или чужой плагин.** Проверка импортов падает.
- **4б. Аргумент или результат вызова не переживает `structuredClone`.** Канал ядра отвечает `NotCloneable`.
- **7а. Задача, кажется, требует ядра.** В ядро она идёт, только если нужна всем плагинам или окну без плагинов и плагин не решит её сам, не нарушив гарантию остальным. Тогда это новая цель ядра в SAD, а не правка под один плагин.

## Постусловия

Плагин выключается в «Плагины Cyborg», не ломая остальных: потребители через `optional` продолжают работать, через `requires` выключаются вместе с ним.
