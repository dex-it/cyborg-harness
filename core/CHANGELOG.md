# Журнал изменений @cyborg-harness/core

Формат - [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии - [semver](https://semver.org/lang/ru/). Выпуск по тегу `v<версия>` (задача P-10, `.github/workflows/release.yml`) требует заголовка `## <версия> - ГГГГ-ММ-ДД` в этом файле: без него выпуск не пройдёт проверку.

## Правило записи

- Изменение публичного имени точки входа (`exports`, перечень в `test/public-api.test.ts`) - строка в `Unreleased` в том же PR; добавление имени - минор, удаление и смена сигнатуры - мажор (до `1.0.0` - минор).
- При выпуске `Unreleased` переименовывается в номер версии и дату, версия в `package.json` повышается тем же коммитом.
